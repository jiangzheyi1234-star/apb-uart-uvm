The offline workbench distributes a locally built SVG chart subset from [Apache ECharts 6.1.0](https://github.com/apache/echarts/tree/6.1.0). Its bundled license material is retained in `web/dashboard/vendor/` and copied alongside generated reports:

The dependency and build-tool versions are pinned in `scripts/dashboard-charts/package-lock.json`. `web/dashboard/vendor/SHA256SUMS` records the distributed bundle and license-file hashes. esbuild is a build-time tool; its installed implementation is not part of the distributed browser bundle.

The optional [Surfer web viewer](https://app.surfer-project.org/) link opens an external service using the project's already published VCD URL. Surfer code is not bundled with this workbench; its service and license terms are independent. Local VCD files and the offline viewer remain available separately.

References to other verification projects are design references; their implementation code is not included. Measured logs, databases, and waveforms are generated by this project's actual runs.
