# 固定版本寄存器与接口说明

依据：PULP Platform [`apb_uart_sv`](https://github.com/pulp-platform/apb_uart_sv/tree/dfad6e04d19cc9481d3cd2750b45b970dc61271b)，提交 `dfad6e04d19cc9481d3cd2750b45b970dc61271b`。本文件记录当前 RTL 的实际行为；不能直接套用完整 16550 软件驱动。代码来源与许可见项目的来源记录及上游 `LICENSE`。

## APB 接口

- 顶层模块：`apb_uart_sv`，位于 `rtl/apb_uart.sv`。默认地址宽度 12，读写数据宽度 32；寄存器只使用低 8 位，读取时高 24 位为零。
- 时钟 `CLK`，异步低有效复位 `RSTN`；串口输入 `rx_i`、输出 `tx_o`，中断输出 `event_o`。
- APB 在 `PSEL && PENABLE` 的访问阶段生效；`PREADY` 恒为 1，`PSLVERR` 恒为 0。FIFO 满时也不会插入等待或报告总线错误。
- **地址按字节连续排列**：译码为 `PADDR[2:0]`，不是常见的 `0x00/0x04/0x08` 步长。高位被忽略，因此每 8 字节镜像一次。基础环境使用 `0x000`～`0x007`。

来源：`rtl/apb_uart.sv:11`、`:35`、`:214`、`:264`、`:342`。

## 寄存器

DLAB 是 `LCR[7]`，使地址 0 和 1 在数据寄存器与分频寄存器之间切换。

| 字节地址 | DLAB | 读 | 写 | 复位 / 备注 |
| --- | --- | --- | --- | --- |
| `0x00` | 0 | RBR：RX FIFO 队首字节，读访问尝试弹出一个元素 | THR：低 8 位尝试进入 TX FIFO | FIFO 复位为空；空读的返回值不应作为有效接收数据 |
| `0x00` | 1 | DLL：分频值低 8 位 | DLL | `0x00` |
| `0x01` | 0 | IER：中断使能寄存器 | IER | `0x00`；仅 `[2:0]` 接入中断模块 |
| `0x01` | 1 | DLM：分频值高 8 位 | DLM | `0x00` |
| `0x02` | 任意 | IIR：`{2'b11, 2'b00, IIR_o[3:0]}` | FCR：FIFO 清除与接收触发门限 | IIR 复位读值 `0xC1`；FCR 没有可读回存储体 |
| `0x03` | 任意 | LCR | LCR | `0x00` |
| `0x04` | 任意 | 零 | 忽略 | MCR 仅有内部复位赋值，没有读写分支 |
| `0x05` | 任意 | LSR | 忽略 | 复位 `0x60`，随后由 FIFO/发送器状态更新 |
| `0x06` | 任意 | 零 | 忽略 | MSR 未实现 |
| `0x07` | 任意 | 零 | 忽略 | SCR 未实现，不能用作普通读写 scratch 寄存器 |

来源：`rtl/apb_uart.sv:216`、`:266`、`:316`。

### LCR

| 位 | 实际功能 |
| --- | --- |
| `[1:0]` | `00/01/10/11` 对应 5/6/7/8 个数据位，低位先传输 |
| `[2]` | TX 停止位选择：0 为 1 位，1 为 2 位；RX 不接此设置 |
| `[3]` | 校验使能；启用时硬件计算偶校验 |
| `[6:4]` | 可写回读，但没有接入串口数据路径；不支持用这些位选择奇校验、固定校验或 break |
| `[7]` | DLAB，控制地址 0/1 的用途 |

8N1 配置值为 `0x03`；8E1 为 `0x0B`。复位 LCR 为 0，即 5 个数据位，不能在复位后直接按 8N1 发送。

来源：`rtl/apb_uart.sv:84`、`:107`；`rtl/uart_tx.sv:50`、`:85`、`:98`、`:123`、`:134`；`rtl/uart_rx.sv:56`。

### LSR

| 位 | 实际功能 / 限制 |
| --- | --- |
| `[0]` | RX FIFO 非空（源码注释写成 empty，但表达式为 `fifo_rx_valid`） |
| `[2]` | 当前 RX FIFO 队首的校验错误标记；本版本该标记实际一直为 0，详见 `rtl_findings.md` |
| `[5]` | TX FIFO 空；不代表串行线上最后一个字节发送完成 |
| `[6]` | `tx_ready && TX FIFO 空`，表示发送移位寄存器和 FIFO 都空 |
| `[7,4:3,1]` | 没有状态更新，保持复位 0；没有 RX 满标记或 overrun/framing 标志 |

状态存储在 `regs_q` 中，相对 FIFO 数量变化存在时钟延迟。读取 RX 数据前应轮询 `[0]`；等待完整 TX 排空应轮询 `[6]`，并为监视器完成最后停止位采样保留余量。

来源：`rtl/apb_uart.sv:205`～`:212`。

### FCR 和中断

- FCR `[1]` 请求清 RX FIFO，`[2]` 请求清 TX FIFO；写入后通过寄存的清除脉冲在后续时钟执行，清除脉冲自动恢复为 0。清除 FIFO **不会终止正在进行的 TX/RX 帧**。
- FCR `[7:6]` 对应 RX 元素数 1、4、8、14 的触发门限；中断模块的比较是 `==`，不是 `>=`。
- FCR `[0]` 没有实现 FIFO 使能控制，FIFO 始终存在。
- IER `[0]` 接收可用/超时使能，`[1]` TX FIFO 空使能，`[2]` 线路状态使能。`CTI_i` 固定为 0，因此没有字符超时中断。
- 当前 IIR 编码为 `0xC1`（复位无中断）、`0xC8`（RX）、`0xC4`（TX）、`0xCC`（线路错误）；不能套用完整 16550 的 IIR 编码。中断接线和清除还有已知问题，基础数据路径测试保持 IER 为 0。

来源：`rtl/apb_uart.sv:175`、`:244`、`:278`、`:285`、`:302`；`rtl/uart_interrupt.sv:43`、`:64`。

## 分频与初始化

`D = {DLM, DLL}`；稳态串口位周期为 **`D + 1` 个 CLK 周期**，不是 `D`，也没有额外的 16 倍过采样因子。TX 第一个起始位受寄存的 `bit_done` 影响，可能比稳态位周期多 1 个时钟。RX 使用三位同步链、下降沿检测和半位起始阶段；应使用足够大的分频值，避免同步/计数的几个时钟开销占据过高比例。默认测试应使用例如 `D=31`（位周期 32 个时钟）。

推荐配置顺序（数据路径空闲时执行）：

1. 写 LCR=`0x83`，打开 DLAB 并选择 8 位。
2. 写地址 0 为 DLL，写地址 1 为 DLM；例如 `D=31` 写 DLL=`0x1F`、DLM=`0x00`。
3. 可在 DLAB 为 1 时读回 DLL/DLM。
4. 写 LCR=`0x03`，恢复 8N1 数据访问。
5. 按需写 FCR=`0x06` 清 FIFO，并等待清除脉冲结束。
6. 确认 IER 为 0 后开始基本收发测试。

来源：`rtl/uart_tx.sv:181`；`rtl/uart_rx.sv:189`、`:202`。本说明没有给零分频或传输中更改 LCR/DLL/DLM 定义通用正确性承诺；这些需要独立的边界测试。

## FIFO 容量与满空行为

- 默认 TX/RX FIFO 均为 16 字节。`io_generic_fifo` 没有空 FIFO 直通路径，数据入队和 TX 接受之间至少有寄存时序。
- TX FIFO 满时，APB THR 写仍完成，但字节被忽略；即使同一周期有 TX 出队，旧的 full 状态仍阻止本周期入队。
- RX FIFO 满时 `rx_ready` 为低。RX 状态机会停在 `SAVE_DATA`，保留一个额外接收字节等待空间。因此“第 17 个 RX 字节必定丢弃”的简单模型不适用；继续注入帧时接收器也无法持续处理后续串行输入。
- 基础 RX 边界测试注入恰好 16 帧，然后按顺序排空；超过容量的行为应单独做特征测试。TX 边界测试须同时考虑已进入移位寄存器的一个字节，不能把“17 次写入”直接等同于“16 个字节输出”。
- 空 RBR 读不会使计数下溢，但数据口仍指向 FIFO 数组，可能返回复位零或先前存储内容；只在 LSR `[0]` 为 1 时比较接收数据。

来源：`rtl/apb_uart.sv:38`；`rtl/io_generic_fifo.sv:46`、`:63`、`:83`、`:121`、`:134`；`rtl/uart_rx.sv:132`。
